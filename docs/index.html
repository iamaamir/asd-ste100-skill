01 / THE WHY

THE PROBLEM ISN'T MORE WORDS.

It's the space between what you write and what someone understands.

Technical instructions leave little room for interpretation. Simplified Technical English is a controlled-language approach to clearer documentation. This open-source skill helps AI agents apply its principles while making uncertainty visible.

✳Clarity is not
a cosmetic change.
02 / THE PROCESS

A system for
clearer thinking.

One skill, three complementary layers. The agent can recommend changes, the checker flags selected structural patterns, and a human approves what matters.

INPUT / 01

ASSIST / 02

07 / GOOD TO KNOW

Questions,
answered.

Everything important before you put the skill to work.

What is Simplified Technical English (STE)? +

ASD-STE100 is a controlled language for technical documentation. It uses writing rules and a controlled dictionary to help reduce ambiguity. This independent skill helps AI agents work with those principles.

Does this automatically guarantee ASD-STE100 compliance? +

No. The skill offers rule guidance, a structural checker, and review prompts. Full lexical and technical compliance requires consulting the official Issue 9 dictionary and qualified review.

Which AI agents can use it? +

The package follows the portable Agent Skills format. Install it with npx skills and select compatible agents available in your environment. Actual agent behavior can vary.

Does the skill send my documentation to a server? +

The included Python checker runs locally without network requests. The browser demo on this page also runs locally. The AI agent that uses the skill may have different data-handling behavior depending on your provider and configuration.

Can I use it without Python? +

Yes. Python 3.9 or later is only required for the optional offline checker. The skill instructions themselves are Markdown and can be loaded by compatible agents without Python.
