01 / HOW IT WORKS

From dense text
to clear actions.

ASD-STE100 Simplified Technical English is a controlled language for technical documentation. This portable skill helps agents draft and review clearer instructions, without hiding uncertainty.

INPUT / 01

Your technical text

Procedures, manuals, system descriptions, and maintenance instructions.

ASSIST / 02

Guided agent review

53 mapped rule IDs, terminology prompts, and optional Python structural checks.

DECIDE / 03

Human-approved result

Rewrite suggestions, flagged findings, and explicit dictionary or safety review gaps.
